# Anteiku asset gallery

Все сгенерированные ассеты проектов семьи Anteiku в одном месте: 486 файлов, разложены по назначению.
Имена файлов латиницей в kebab-case и описывают, что на картинке. В каждой папке есть README со списком и превью.

## Стиль

Глянцевая мягкая 3D-глина: один крупный объект, кремовые и насыщенные цвета, вокруг жёлтые глиняные звёзды,
кремовые шарики и одна тонкая орбита. Фон сплошной, без градиента. Эталоны: `cards/game-covers`,
`brand/anteicut/avatar-1024.png`, `alternates/misc/reference-play-button-good.jpg`.
Генерация: Higgsfield, модель GPT Image 2.5, в роли референса одна из обложек отсюда.
Новые иконки режутся из фона и приводятся к одной оптической величине.

## Откуда

- **AnteikuAnon** (`anteiku-live`): иконки, плитки, игры, мафия, бункер, портреты, рамки, фоны, видео, сундук.
- **AnteiCut** (`AnteikuCut`): карточки разделов, обложки бота, бренд, часть иконок.
- **Анонка** (`anonka`): карточки разделов, обложки бота, бренд, арт сторис.
- **Evely**: бренд, донат и режимы, видео сакура-мира.
- **AnteikuMediaUtils**: мелкие ассеты интерфейса.
- `alternates`, `legacy`, `originals`: неиспользованные варианты, прошлые версии и исходники высокого разрешения.

Скриншоты QA, ассеты сторонних наборов и плагинов сюда не входят.
