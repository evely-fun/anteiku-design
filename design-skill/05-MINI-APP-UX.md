# 05. Мини-приложение: как делаем

Смотри `screens/anonka/`, `screens/chekni/`, `screens/anteicut/`, `screens/anteiku-anon/`.
Код-эталон: `reference/code/frontend/` (Анонка).

## Каркас

- React 19, Vite 8, Tailwind 4, `motion` (LazyMotion + `domMax`, `m.*`), без роутера: своя навигация
  (`navigation.tsx`) с вкладками (`Tab`) и push-экранами (`Page`) с параметром.
- Ширина контента `max-w-[480px]` по центру. На ПК это аккуратная колонка, а не растянутый телефон.
- Вкладки: 3 штуки в плавающем таббаре снизу. Push-экраны прячут таббар и включают нативную
  `BackButton` Telegram, в браузере свою стрелку.
- `?screen=` в URL открывает нужный экран прямо из кнопки бота (сторис, статистика, жалоба `&id=`).
- Провайдеры: Theme → Toast → Profile → I18n → Navigation.

## Telegram-интеграция (`telegram.ts`)

`ready()` и `expand()` сразу, `disableVerticalSwipes()`, цвет шапки и фона под тему (`paintChrome`),
safe area (`--tg-safe-area-inset-*`), вибрация на нажатие и итог (`HapticFeedback`), `openInvoice` для Stars,
`shareToStory` с `widget_link`, `openTelegramLink` для шаринга, никакого белого экрана в тёмной теме.
Все запросы к API подписаны `X-Telegram-Init-Data`, сервер проверяет HMAC.

## Композиция экрана

1. Заголовок: маленькая строка контекста (`ink-soft`, 14/600) + крупный заголовок 28/800.
2. Hero-блок цвета бренда (радиус 28) с главным действием, текст белый, кнопки `paper` + прозрачная белая.
3. Ряд из 2–3 цифр в белых карточках.
4. Карточки разделов: картинка на весь блок, цвет фона = цвет арта, заголовок 19/800 белым в пустом углу.
   Большая карточка во всю ширину 16:10, маленькие по две 9:10. Premium отдельной янтарной полосой 16:7.
5. Внизу тихая строка обещания продукта (`ink-faint`, по центру).

Одна задача на экран. Больше пяти целей нажатия над сгибом значит два экрана.

## Компоненты (`kit.tsx`)

`Pressable` (нажатие + вибрация), `Action` (кнопка 52 px, тоны ink/soft/danger/paper, `busy` со спиннером),
`TabTitle`, `PageHeader`, `Sheet` (шторка снизу, свайп вниз закрывает), `Segmented` (перетекающая подложка),
`Switch`, `Group` + `Row` (настройки), `EmptyState` (глиняная иконка 88 px + заголовок + одна строка + кнопка),
`Mark` (глиняная иконка), `Rail` (горизонтальная лента, крутится колесом и перетаскивается мышью на ПК).
Графики админки: `charts.tsx` (TimeSeries, Bars, Rows, Heat), одна серия одним тоном.

## Состояния

- Загрузка: скелетоны той же формы, не спиннер на весь экран.
- Пусто: `EmptyState` с понятным следующим шагом («Кинь ссылку в сторис»).
- Ошибка: человеческий текст и «Ещё раз». Код ошибки сервера переводится в текст (`reject.*`).
- Офлайн и «открыто не в Telegram»: отдельные экраны.
- Нет доступа (роль): отдельный экран, а не пустая страница.
- Оптимистичные действия там, где безопасно; тосты сверху, не перекрывают таббар.

## Выбор и выделение

Выбранный вариант должен быть виден без подписи: рамка 2 px цветом раздела + wash-подложка + кружок-галочка.
Не полагаться на `ring` поверх `shadow-float` (он пропадает).

## ПК

Мини-приложения открывают и в Telegram Desktop. Обязательно:
- вертикальные списки крутятся колесом (обычный скролл документа, без вложенных скроллов без нужды);
- горизонтальные ленты (вкладки, чипы) через `Rail`/`useRail`: колесо крутит вбок, мышь перетаскивает,
  клик после перетаскивания не срабатывает;
- у полей ввода рядом с кнопкой `min-w-0`, у кнопки `shrink-0`, иначе на 360 px вылезает вбок.

## Админ-панель

Роли: владелец (ID в `.env`) видит всё, админ видит только жалобы и работает с ними.
Панель внутри мини-приложения (Настройки → Панель): очередь жалоб с фильтрами-чипами, карточка жалобы
с перепиской пузырями, историей отправителя, тегами и заметкой, решения «Забанить / Страйк / Отклонить»,
«В чат 1 в 1». Статистика как в AnteiCut: KPI-плитки 3 в ряд, графики по дням, часы, тепловая карта.
Правила графиков: `reference/docs/anteicut-ANALYTICS.md`.

## Языки

ru и en всегда вместе в `i18n/strings.ts`, язык берётся из профиля на сервере, по умолчанию русский.
Плюрали через функцию `plural` с тремя формами.
