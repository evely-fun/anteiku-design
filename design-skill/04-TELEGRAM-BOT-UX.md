# 04. Чат-бот: как делаем

Эталоны кода: `reference/code/bot/keyboards.py`, `texts.py`, `covers.py`, `profile.py`, `delivery.py`
(Анонка), `chekni-present.py` (rich-отчёты Чекни), `anteicut-i18n.py` (тексты AnteiCut).
Стек: aiogram 3.31+ (Bot API 10.x), `parse_mode=HTML`, превью ссылок выключены по умолчанию.

## Профиль бота

- Имя, короткое описание, описание и команды **бот публикует сам при старте** (`profile.publish`),
  только если они изменились (хэш в Redis), иначе ловит flood limit на `setMyName`.
- **Основной язык русский.** Профиль ставится без `language_code`, а версии для `en`, `uk`, `be`, `kk`, `uz`
  очищаются пустыми строками, чтобы англоязычный Telegram тоже видел русский.
- Аватар бот ставит сам (`set_my_profile_photo`), картинку описания владелец грузит в BotFather.
- Команды: 5–9 штук, описания короткие без эмодзи («Моя ссылка», «Статистика», «Настройки»).
  Админам отдельный список через `BotCommandScopeChat`.
- Кнопка меню: `MenuButtonWebApp` с названием бренда, открывает мини-приложение.

## Ключевые экраны идут фото с подписью

`/start`, `/premium`, `/stats`: `send_photo(обложка 16:9, caption, keyboard)`. `file_id` кэшируется.
Первое сообщение нового пользователя приходит с эффектом 🎉 (`message_effect_id="5046509860389126442"`).

Подпись `/start` строится так:

```
<b>Короткий заголовок, что тут происходит</b>

1–2 предложения сути. Одно предложение про главное обещание.

<ссылка или главный факт>

Одна подсказка, как получить пользу быстрее.
```

## Кнопки

Цвета кнопок из Bot API 9.4 (`style`), используем осмысленно, не красим всё:

| style | когда | пример |
| --- | --- | --- |
| `PRIMARY` синий | главное действие экрана | «Скопировать ссылку», «Ответить», «Открыть панель» |
| `SUCCESS` зелёный | наша фишка или покупка | «Открыть анонку» (мини-приложение), «Подписаться», «Хочу свою ссылку» |
| `DANGER` красный | необратимое и блок | «Заблокировать», «Удалить навсегда», «Забанить отправителя» |
| без стиля | всё остальное | «Отправить друзьям», «Настройки», «Назад» |

Правила раскладки:

- Главная кнопка одна и во всю ширину, первая строка. Вторичные парами во второй-третьей строке.
- `copy_text` для копирования ссылки (без переходов), `url=https://t.me/share/url?...` для «отправить друзьям»,
  `web_app` для мини-приложения и сторис.
- Длинные меню прячем за «Ещё»: `Ответить` / реакции / `Ещё` → раскрывается в `Заблокировать · Пожаловаться` + `Назад`.
  Переключаем `edit_reply_markup`, не шлём новое сообщение.
- Переключатели настроек: одна кнопка на пункт с состоянием в тексте («Фильтр грубости: вкл»), нажатие
  меняет и перерисовывает клавиатуру, в ответ тост «Сохранено».
- Выбор из вариантов: у текущего `PRIMARY`, у остальных без стиля (так в AnteiCut выбор формата и языка).
- В `callback_data` **никогда** нет Telegram ID и персональных данных. Только `action:public_id` (12 случайных символов).
- Каждый callback закрываем `callback.answer()`: пустой или тост, `show_alert=True` только для важного.

## Поведение

- Одна задача, одно сообщение. Меняющееся состояние **редактируем** (`edit_text`, `edit_caption`,
  `edit_reply_markup`), а не спамим новыми. Прогресс (как проверка в Чекни) это одно сообщение с галочками шагов.
- Ввод ждём через состояние в Redis (`await:{tg_id}` = nick / prompt / support) с TTL и кнопкой «Отмена».
- Реакции бота как тихое подтверждение: в Анонке реакция ставится на исходное сообщение автора,
  в Чекни 👀 пока проверяю, 👌 чисто, 🤔 сомнения, 😱 опасно.
- Ответы в переписке приходят `reply_parameters` к исходному сообщению, чтобы была нативная цитата.
- Антифлуд: мягкий кулдаун на сообщения («Полегче, не так быстро.» один раз, потом молча).
- Длинные подробности в `<blockquote expandable>`. Rich-сообщения (Bot API 10.1+) с откатом на HTML.
- В группах тихо: только реакции, текст только когда важно (Чекни).

## Форматирование текста

- `<b>` только для заголовка сообщения и одной-двух ключевых цифр. Не жирним полтекста.
- Списки: `•` или просто строки. Эмодзи-буллеты запрещены.
- Одно эмодзи на сообщение максимум и только если оно что-то значит (статус, реакция, звезда в цене `99 ⭐`).
- Ссылку пользователя показываем полностью, отдельной строкой.

## Обязательные вещи продукта

- Возраст при первом запуске (кнопки диапазонов), согласие с условиями в том же сообщении со ссылками.
- `/help`, `/terms` (условия + конфиденциальность + безопасность), `/support`, `/paysupport` (Telegram требует для Stars),
  `/mydata` (выгрузка JSON), `/deletedata` (удалить всё с подтверждением).
- Оплата только Telegram Stars. Перед подпиской отдельное сообщение с условиями и кнопкой «Подписаться, 99 ⭐ в месяц»,
  согласие пишется в базу. Отмена автопродления в боте и в приложении.
- Жалобы с причинами, срочные (интимное без согласия, дети) убирают сообщение сразу.
- Админ-карточки в чате с кнопками решения и «Открыть в панели» (web_app). Админ видит только внутренние номера u123.

## Анонимность (для анонимных продуктов)

Имя автора не показываем никому и никогда не продаём. Фейковых сообщений от бота нет.
Это одновременно продукт, этика и защита от дела NGL (FTC, $5M). Подробно `reference/docs/anonka-FEATURES.md`.
