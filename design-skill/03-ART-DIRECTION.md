# 03. Арт: глянцевая 3D-глина

Открой и посмотри: `art/game-covers/`, `art/avatars/`, `art/banners/`, `art/section-cards/`, `art/bot-covers/`,
`art/verdicts/`, `art/icons/`, `art/reference-good-play-button.jpg` (владелец отметил его как «хороший пример»).

## Как выглядит

- **Один крупный главный объект** из мягкого глянцевого пластика или глины, чаще кремового цвета,
  с мягкими бликами. Объект простой и читаемый: облачко-чат, щит, стрелка, конверт, корона, шляпа.
- **Мелочь вокруг**: 4–7 жёлтых глиняных звёздочек, несколько кремовых шариков, **одна тонкая кремовая орбита**
  вокруг объекта. Иногда 1–2 маленьких вторичных объекта (нота, лупа, монеты).
- **Фон сплошной, насыщенный, плоский, без градиента.** Лёгкая тень под объектом.
- **Акцентная деталь чёрная или цветная**: маска у Анонки, галочка у Чекни, play у AnteiCut.
- **Без текста на арте.** Исключение только баннер описания бота (жирный белый Montserrat слева, объект справа).
- Никаких людей в реалистичном стиле. Персонажи только чиби-глина (портреты AnteikuAnon).

## Чем генерируем

**Higgsfield**, модель `gpt_image_2_5`, `quality: medium`, 1k (≈1 кредит за картинку; high и 2k дороже в 3 раза).
Всегда прикладывай 1–2 референса стиля (`medias` с ролью `image_references`):
аватар Анонки (`art/avatars/anonka.png`) или AnteiCut (`art/avatars/anteicut.png`), для баннера баннер AnteiCut.
Для этого загрузи файл через `media_upload` (PUT по выданной ссылке, затем `media_confirm`).

### Промпт-основа

```
<что за объект> in the exact same glossy soft 3D clay style as the reference: one big centered
cream-white glossy clay <объект> <деталь бренда>, soft highlights, subtle shadow under it.
Around it a few small butter-yellow clay stars, tiny cream clay balls and one thin cream orbit ring.
Solid saturated <цвет> background (<hex>-ish), flat, no gradient, no text, no letters.
<композиция>. Clean, premium, playful, not childish.
```

Композиция по назначению:

| что | формат | композиция |
| --- | --- | --- |
| аватар бота | 1:1, 1024 | «centered with generous margin so it survives a circular crop» |
| картинка описания / баннер | 16:9 (1344×752) | текст слева крупно, объект справа, «exact Russian spelling» |
| обложка сообщения бота | 16:9 | «object centered-right, plenty of empty space», без текста |
| карточка раздела мини-приложения | 9:8 | «objects in the right and lower part, top-left quarter left empty» (туда кладём подпись в UI) |
| фон для сторис | 9:16 | объект в верхней трети, низ пустой под текст |
| иконка-метка | 1:1, `background: transparent` | один объект, без звёзд, прозрачный фон |

### После генерации

- Всегда смотри результат глазами. Если стиль ушёл, перегенерируй с другим референсом, не выдумывай.
- **Перекраска без новой генерации**: если фон плоский, вырежи объект по цветовому ключу
  (расстояние до цвета фона → альфа), и ставь его на любой цвет. Так сделаны 6 цветов карточки сторис Анонки
  (`art/story-art-transparent.png`, код `reference/code/bot/render.py`).
- Иконки вырезать из фона и нормализовать к одной оптической величине (192 px).
- Сохранять в webp (q 86–90) для фронта, jpg (q 90) для обложек бота, png для аватара и баннера BotFather.

## Размеры для Telegram

| что | размер | как ставится |
| --- | --- | --- |
| аватар бота | jpg, квадрат 640+ | бот ставит сам: `set_my_profile_photo(InputProfilePhotoStatic)` при старте |
| картинка описания (над «Начать») | 640×360 | только вручную: @BotFather → Edit Bot → Edit Description Picture (в Bot API метода нет) |
| обложки сообщений | 1344×752 jpg | `send_photo`, `file_id` кэшировать в Redis |
| карточка для сторис | 1080×1920 jpg | рендер Pillow + `WebApp.shareToStory` |
| фавикон мини-приложения | 96×96 webp | `frontend/public/favicon.webp` |

## Цвета фонов, которые уже использованы

Синий `#1a84f7`, коралловый `#f64b41`/`#ee5a3f`, фиолетовый `#8a57f3`, изумрудный `#09ad7c`/`#10b27a`,
янтарный `#f2a31f`, сланцевый `#6b7a90`, насыщенный красный (обложка городской мафии, сундук), тёмно-бирюзовый (старые баннеры AnteikuAnon).
В UI фон карточки задаётся тем же hex, что и фон арта, чтобы при `object-cover` не было полосы.
