# Дизайн

Семья Anteiku: AnteikuAnon (обложки игр) и AnteiCut. Тот же язык, свой цвет.

## Графика

Глянцевая мягкая 3D-глина: крупный кремовый объект, чёрная маска как знак анонимности,
вокруг жёлтые глиняные звёзды, кремовые шарики и одна тонкая орбита. Фон сплошной,
насыщенный, без градиента. Текста на арте нет, кроме баннера описания.

Всё сгенерировано в Higgsfield (GPT Image 2.5, medium) с аватаром и баннером AnteiCut
в роли референса стиля. Исходники: `docs/brand/`, `backend/app/assets/covers/`,
`frontend/src/assets/cards/`. Арт для сторис вырезан из синего фона по цветовому ключу,
поэтому карточка перекрашивается в любой цвет без новой генерации.

## Цвет обозначает раздел

| раздел | цвет |
| --- | --- |
| ссылка | синий `#1a84f7` |
| входящие | коралловый `#f64b41` |
| сторис | фиолетовый `#8a57f3` |
| статистика | изумрудный `#09ad7c` |
| premium | янтарный `#f2a31f` |

Кнопки действия чернильные: почти чёрная на бумаге, светлая в тёмной теме.
Бумага тёплая, не чистый белый. Тёмная тема полноценная.

## Правила

- Montserrat, sentence case, никакого капслока и разреженных лейблов.
- Нет градиентов, свечений и blur на поверхностях.
- Глиняные метки для того, что называет вещь; штриховые глифы для того, на что нажимают.
- Моушн: подъём 12px и fade на `cubic-bezier(0.23, 1, 0.32, 1)`, нажатие `scale(0.97)`,
  стаггер 35мс и не дальше шестого элемента, `prefers-reduced-motion` уважается.
- Telegram: нативная BackButton, `disableVerticalSwipes`, safe area, цвет шапки из темы.

## В боте

Ключевые экраны идут фото с подписью (`/start`, `/stats`, `/premium`), file_id кэшируется.
Кнопки с цветом Bot API 9.4: главное действие `primary`, опасное `danger`, покупка `success`.
Первое полученное сообщение и оплата приходят с эффектом 🎉.
