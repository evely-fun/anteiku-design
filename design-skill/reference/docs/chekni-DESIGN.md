# Дизайн

Семья Anteiku: Анонка (синяя, маска), AnteiCut (коралловая, стрелка), Чекни (изумрудная, щит).
Тот же язык, свой цвет.

## Графика

Глянцевая мягкая 3D-глина: крупный кремовый объект, вокруг жёлтые глиняные звёзды, кремовые шарики
и одна тонкая орбита. Фон сплошной, насыщенный, без градиента. Текста на арте нет, кроме баннера описания.

Сгенерировано в Higgsfield (GPT Image 2.5, medium) с аватарами Анонки и AnteiCut как референсом стиля.
Исходники в `docs/brand/raw/`, готовые файлы:

| файл | куда |
| --- | --- |
| `docs/brand/avatar-640x640.png`, `backend/app/assets/covers/avatar.jpg` | аватар, бот ставит сам |
| `docs/brand/description-640x360.png` | @BotFather `/setdescriptionpic` |
| `backend/app/assets/covers/start.jpg`, `premium.jpg` | обложки `/start` и `/premium` |
| `frontend/public/art/verdict-{clean,suspicious,malicious,unknown}.jpg` | шапка rich-отчёта |
| `frontend/src/assets/cards/{scan,guard,history,premium}.webp` | карточки мини-приложения |

Промпт-основа для новой графики: «glossy soft 3D clay render, one large cream glossy clay object,
small yellow clay stars, tiny cream clay balls, one thin cream orbit ring, solid saturated {цвет}
background, flat, no gradient, soft shadow, no text» плюс аватар Анонки референсом.

## Цвет обозначает раздел и вердикт

| что | цвет |
| --- | --- |
| проверка, «чисто» | изумрудный `#10b27a` |
| история | синий `#1a84f7` |
| чаты | фиолетовый `#8a57f3` |
| premium, «есть сомнения» | янтарный `#f2a31f` |
| «опасно» | коралловый `#f64b41` |
| «не вышло» | сланцевый `#6b7a90` |

Кнопки действия чернильные. Бумага тёплая, тёмная тема полноценная.

## В боте

- Отчёт это rich-сообщение Bot API 10.1+: картинка вердикта, заголовок, таблица фактов,
  сворачиваемые «Кто что нашёл», «Что ещё заметил», «Отпечатки», футер. Если клиент или API
  не приняли rich, бот на час переключается на обычный HTML с `blockquote expandable`.
- Прогресс редактирует одно сообщение: галочки пройденных шагов и текущий шаг.
- Реакции на исходном файле: 👀 пока проверяю, 👌 чисто, 🤔 сомнения, 😱 опасно.
- Цвет кнопок Bot API 9.4: отчёт на опасный файл `danger`, остальное `primary`, покупка `success`.
- Эффект 👍 на чистый новый файл в личке, если пользователь не выключил анимации.
- В группах тихий режим по умолчанию: чистым файлам только реакция, ответ приходит на угрозы.
  «Подробнее» показывает полный отчёт эфемерным сообщением только нажавшему (Bot API 10.3).
