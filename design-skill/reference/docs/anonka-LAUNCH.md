# Перед запуском

Код закрывает всё, что можно закрыть кодом. Ниже то, что может сделать только оператор.

## Обязательно

1. **Картинка описания.** @BotFather, `/mybots`, бот, Edit Bot, Edit Description Picture,
   файл `docs/brand/description-640x360.png`. Через Bot API её поставить нельзя.
2. **Адрес мини-приложения в BotFather:** `https://anonka.40-160-90-130.sslip.io`.
3. **Ссылка на политику в BotFather:** Edit Bot, Privacy Policy,
   `https://anonka.40-160-90-130.sslip.io/legal/privacy-ru.html`. Этого требуют правила
   Telegram для ботов с собственной политикой.
4. **Регистрация в NCMEC как провайдер** (`esp.ncmec.org/registration` или espteam@ncmec.org).
   Сервер в США, поэтому при получении информации о материалах сексуального насилия над
   детьми есть обязанность сообщить в CyberTipline (18 U.S.C. § 2258A). Порядок действий в `SAFETY.md`.
5. **Публичный email для жалоб.** Сейчас везде указан `/support` в боте. Для запросов от
   людей без Telegram (TAKE IT DOWN, авторские права, полиция) нужен ящик; когда появится,
   добавить его на страницы в `frontend/public/legal/`.

## Желательно

- Разовая консультация юриста США по выбору права (сейчас Делавэр), ограничению
  ответственности и минимальному возрасту. Сейчас минимум 14 лет (`MIN_AGE` в `.env`).
  Юридически безопаснее 16+: во Флориде действует HB3 (до 14 запрещено, 14–15 с согласия
  родителей). Если заметная доля аудитории окажется из США, стоит поднять возраст.
- Регистрация DMCA-агента (6 долларов на 3 года) даёт защиту safe harbor по авторским правам.
- Если оператор физически в России: сервер в США формально противоречит требованию хранить
  данные граждан РФ в России (152-ФЗ). Это риск оператора, его стоит оценить отдельно.

## Проверено кодом

| обещание в документах | где реализовано |
| --- | --- |
| возраст спрашивается до начала работы, младше 14 не пускаем и не храним | `bot/middlewares.py`, `domain/privacy.py` |
| для младше 18 фильтр грубости включён, ссылки выключены | `privacy.accept_age` |
| автора не раскрываем, в кнопках и API нет Telegram ID | `tests/test_flow.py`, `tests/test_api.py` |
| угрозы не доставляются, три страйка это бан | `domain/filters.py`, `inbox._strike` |
| интимное и детское убирается из чата сразу, детское под legal hold | `inbox._contain` |
| legal hold не удаляется ни ретеншеном, ни удалением аккаунта | `retention.py`, `privacy.erase` |
| выгрузка данных и удаление всего | `/mydata`, `/deletedata`, `/api/me/export`, `/api/me/erase` |
| отдельное согласие на автопродление, запись согласия 3 года | `premium.agree`, `Consent`, `retention.py` |
| отмена подписки в боте и в приложении | `unsubscribe`, `/api/billing/cancel` |
| поддержка и ответы через бота | `/support`, `admin.answer_ticket` |
| сроки хранения 365 дней, 7 дней, 13 месяцев, 5 лет, бэкапы 14 дней | `retention.py`, `deploy/backup.sh` |
| IP-адреса не хранятся | `access_log off` в nginx, uvicorn без access log |
