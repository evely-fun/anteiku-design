# 02. Визуальная система

Эталонный файл токенов: `reference/code/frontend/anonka-index.css` (Анонка) и `chekni-index.css` (Чекни).
Они совпадают во всём, кроме цветов разделов. AnteikuAnon устроен сложнее (палитры на выбор),
его токены в `anteiku-anon-index.css`.

## Философия

Светлое, плоское, просторное, мягкие формы, один уверенный цвет на вещь. Игриво, но не игрушечно.
Спокойный экран, на котором всё равно ярко, потому что цвет используется по назначению.

1. **Светлая тема по умолчанию**, тёмная полноценная, не «инвертированная». Проверяются обе, каждый раз.
   Режим «Авто» берёт тему из Telegram (`themeParams`/`colorScheme`).
2. **Бумага тёплая**, не чистый белый и не серый: `oklch(0.975 0.006 75)`.
3. **Цвет обозначает раздел, а не украшает.** Экран показывает свой цвет и почти ничего больше.
   Нет одного глобального акцента, которым залито всё.
4. **Действия чернильные.** Главная кнопка почти чёрная на бумаге и светлая в тёмной теме.
   Цвет говорит, что это за раздел; контраст говорит, на что нажимать.
5. **Нет градиентов на поверхностях, нет цветных свечений, нет матового стекла (backdrop-blur).**
   Градиенты живут только внутри нарисованного арта.
6. **Sentence case.** Никакого капслока и разреженных микролейблов над блоками.
7. **Пространство главный инструмент.** Тесно, значит убрать лишнее, а не уменьшить шрифт.

## Токены (Анонка, Чекни, AnteiCut)

| токен | светлая | тёмная |
| --- | --- | --- |
| `--paper` фон | `oklch(0.975 0.006 75)` | `oklch(0.165 0.01 265)` |
| `--card` карточки | `oklch(1 0 0)` | `oklch(0.215 0.012 265)` |
| `--well` углубления, поля ввода | `oklch(0.945 0.007 75)` | `oklch(0.255 0.013 265)` |
| `--rim` обводки, выключенный свитч | `oklch(0.885 0.009 75)` | `oklch(0.34 0.013 265)` |
| `--ink` основной текст | `oklch(0.23 0.018 265)` | `oklch(0.965 0.005 75)` |
| `--ink-soft` вторичный | `oklch(0.47 0.016 265)` | `oklch(0.76 0.012 265)` |
| `--ink-faint` подписи | `oklch(0.6 0.013 265)` | `oklch(0.62 0.013 265)` |
| `--line` разделители | `ink / 0.08` | `white / 0.075` |
| `--action` главная кнопка | `= ink` | `oklch(0.95 0.006 75)` |
| `--on-action` текст на ней | `oklch(0.985 0.004 75)` | `oklch(0.2 0.015 265)` |

Каждый цвет раздела имеет пару: `--x` (заливка, текст-акцент) и `--x-wash` (тот же цвет с 12–16%
прозрачности для подложек и чипов). В тёмной теме цвета светлее и чуть менее насыщенные.

Тени только две, нейтральные, низкие:

```css
--shadow-soft:  0 1px 2px ink/6%, 0 10px 24px -14px ink/22%;
--shadow-float: 0 1px 2px ink/8%, 0 18px 40px -18px ink/35%;
```

Внимание: в Tailwind `ring-*` рисуется тенью, и `shadow-float` её перебивает. Выделение
выбранного делаем рамкой (`border-2 border-premium`) и подложкой (`bg-premium-wash`), см. Premium Анонки.

## Шрифт

**Montserrat Variable** через `@fontsource-variable/montserrat`, локально, не с Google Fonts.
Не Inter, не Geist, не Space Grotesk, никаких курсивных засечек для «акцентного слова».

| роль | размер | вес |
| --- | --- | --- |
| заголовок вкладки | 28 | 800, `tracking-[-0.025em]` |
| заголовок страницы | 20 | 800 |
| заголовок карточки / группы | 15–19 | 700–800 |
| основной | 15 | 400–600 |
| вторичный | 12.5–13.5 | 400–600 |
| мета, подписи | 11–12 | 600 |

Цифры, которые меняются, всегда `tabular-nums` (утилита `.tabular`).

## Форма

- Радиусы: **14** контролы и поля, **16** большие кнопки, **18–22** карточки, **26–28** hero-блоки и шторки,
  **full** пилюли, чипы, аватары.
- Кнопка действия: высота 52, радиус 16, жирный 15. Тона: `ink` (главная), `soft` (вторичная на `well`),
  `danger` (`danger-wash` + красный текст), `paper` (белая на цветном hero).
- Таббар: плавающий остров снизу, `bg-card`, радиус 26, высота 66, `shadow-float`, 3 пункта с глиняными
  иконками, активный подсвечивается перетекающей подложкой `layoutId`. Неактивные иконки в `grayscale`.
- Группы настроек: белая карточка радиус 22, строки разделены `border-line`, у строки глиняная иконка 30 px,
  заголовок 15/600, пояснение 12.5.

## Моушн (`reference/code/frontend/motion.ts`)

- Появление: подъём 12 px + fade, 260–420 мс, `cubic-bezier(0.23, 1, 0.32, 1)`.
- Шторки: `cubic-bezier(0.32, 0.72, 0, 1)`, закрываются свайпом вниз.
- Нажатие: `scale(0.97)` на жёсткой пружине (`stiffness 560, damping 34`) + лёгкая вибрация Telegram.
- Стаггер списков 35–45 мс, не дальше шестого элемента.
- Ничего не пульсирует, не прыгает на hover и не мерцает само по себе. Скелетоны мерцают только пока грузится.
- `prefers-reduced-motion` уважается (`MotionConfig reducedMotion="user"`).

## Иконки

- **Глиняные метки** (webp с прозрачностью, 128–192 px) называют вещи: разделы, пункты меню, перки.
  Полный набор: `art/icons/`, галерея `asset-gallery/icons/clay`.
- **Штриховые глифы** (SVG, stroke 1.9, скруглённые концы) для того, на что нажимают: назад, копировать,
  отправить, ещё, галочка, замок. См. `reference/code/frontend/icons.tsx`.
- Никаких эмодзи вместо иконок в интерфейсе. Никакого голого Lucide.

## AnteikuAnon отдельно

Тот же язык, но ещё: цвет каждого раздела задан hue (`search 28, rooms 245, games 292, friends 158,
profile 62`), пользователь может выбрать палитру фона и акцента (obsidian, indigo, moss, amethyst,
terracotta, dusk, cobalt, garnet), есть живые голосовые визуализации. Подробно `reference/docs/anteiku-anon-DESIGN.md`.
